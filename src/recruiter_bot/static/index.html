Raw, hand-written SQL queries crafted to answer the hiring ops scenario questions without redesigning the dataset. Verified against duplicate profile anomalies, case mismatches, and window-function placements.

Question 1

List all currently open job postings, along with the recruiter who owns each one.

SELECT
    jp.id AS job_posting_id,
    jp.title AS job_title,
    jp.department,
    jp.opened_date,
    r.name AS recruiter_name
FROM job_postings jp
JOIN recruiters r ON jp.recruiter_id = r.id
WHERE jp.status = 'open'
ORDER BY jp.id;

Question 2

For each job posting, how many applicants reached the Final interview stage?

SELECT
    jp.id AS job_posting_id,
    jp.title AS job_title,
    COUNT(DISTINCT i.applicant_id) AS final_stage_applicant_count
FROM job_postings jp
LEFT JOIN interviews i
    ON jp.id = i.job_posting_id
    AND i.stage = 'Final'
GROUP BY jp.id, jp.title
ORDER BY jp.id;

Question 3

Find every person who effectively applied to more than one job posting (with duplicate profile handling).

SELECT
    LOWER(TRIM(a.email)) AS normalized_email,
    MIN(a.full_name) AS person_name,
    COUNT(DISTINCT i.job_posting_id) AS distinct_jobs_applied_count,
    GROUP_CONCAT(DISTINCT i.job_posting_id) AS job_posting_ids
FROM applicants a
JOIN interviews i ON a.id = i.applicant_id
GROUP BY LOWER(TRIM(a.email))
HAVING COUNT(DISTINCT i.job_posting_id) > 1
ORDER BY person_name;

Question 4

Recruiter Final-stage conversion rate (for recruiters with at least 3 Final interviews).

SELECT
    r.id AS recruiter_id,
    r.name AS recruiter_name,
    COUNT(*) AS total_final_interviews,
    SUM(CASE WHEN i.outcome = 'passed' THEN 1 ELSE 0 END) AS passed_final_interviews,
    ROUND(
        SUM(CASE WHEN i.outcome = 'passed' THEN 1.0 ELSE 0.0 END) / COUNT(*),
        4
    ) AS final_stage_conversion_rate
FROM recruiters r
JOIN job_postings jp ON r.id = jp.recruiter_id
JOIN interviews i ON jp.id = i.job_posting_id
WHERE i.stage = 'Final'
GROUP BY r.id, r.name
HAVING COUNT(*) >= 3
ORDER BY final_stage_conversion_rate DESC, r.name ASC;

Question 5 (Bonus)

Window function: Find recruiter with the most successful placements per department.

WITH department_recruiter_placements AS (
    SELECT
        jp.department,
        r.id AS recruiter_id,
        r.name AS recruiter_name,
        COUNT(i.id) AS successful_placements,
        DENSE_RANK() OVER (
            PARTITION BY jp.department
            ORDER BY COUNT(i.id) DESC
        ) AS rank_in_department
    FROM recruiters r
    JOIN job_postings jp ON r.id = jp.recruiter_id
    JOIN interviews i ON jp.id = i.job_posting_id
    WHERE i.stage = 'Final' AND i.outcome = 'passed'
    GROUP BY jp.department, r.id, r.name
)
SELECT
    department,
    recruiter_id,
    recruiter_name,
    successful_placements
FROM department_recruiter_placements
WHERE rank_in_department = 1
ORDER BY department;
